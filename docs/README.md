## Словник

| Термін | Значення |
|---|---|
| Рендер | Відкрити адресу в ізольованому Chromium і зібрати скриншот, текст, форми, редиректи |
| Вердикт | `phishing` / `suspicious` / `safe` / `unreachable` для однієї адреси |
| Офіційний домен | Домен бренду з `brands.json` або з `official` у налаштуваннях моніторингу |
| Клон | Сторонній домен, що імітує бренд |
| Візит «з реклами» | Рендер із `fbclid` і `Referer: l.facebook.com`: так клон показують жертвам із реклами |
| Кнопка-приманка (CTA) | Головна кнопка сторінки без форм; сервіс натискає її й знімає наступний екран |
| CT, журнал сертифікатів | Certificate Transparency: публічний журнал усіх виданих SSL-сертифікатів (crt.sh) |
| RDAP | Протокол реєстраційних даних домену: вік, реєстратор, контакт для скарг |
