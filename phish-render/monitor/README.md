# Моніторинг клонів

Щоденний прогін `tools/brand_audit.py`, порівняння з попереднім днем і сповіщення в Telegram.
Керування з Mac: `bash monitor.sh telegram | run | on | off | status [бренд]`.

- `<бренд>.json` — офіційні домени (`official`), домени з новин (`extra`), відомі безпечні (`ignore`:
  домен або цілий сайт, як `crevv.com`, і чому), чати клієнта (`client_chats`), чи слати клієнту щоденне
  зведення (`client_digest`). Адміну зведення приходить щодня.
- `telegram.env`, `state/`, `runs/` створюються на сервері й в архів не потрапляють.
- Таймер: щодня о 07:40 за Києвом (±10 хв). Ставиться вимкненим, вмикається лише командою `on`.
